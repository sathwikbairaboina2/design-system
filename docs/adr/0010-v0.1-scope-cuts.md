# ADR 0010: What v0.1 does not do

Date: 2026-10-04 · Status: accepted

## Decision
v0.1 ships tokens, eight components plus ThemeProvider and layout primitives, Storybook, a11y and visual tests,
two remotes, contract and e2e tests, a Docker demo and CI. It does not ship:
- Changesets releases or an npm publish (no registry credentials on an unattended run). `pnpm pack:smoke` proves the
  tarballs are complete instead.
- api-extractor reports (invariant 10 of the design) or `size-limit` budgets. The report records gzip sizes only.
- A live hosted micro-frontend demo. `pages.yml` publishes Storybook once the repo is pushed; it is unrun until then.
- Select, Checkbox, Switch, Toast, Table, the token gallery page, Figma sync, SSR.

## What I gave up
- **"Something others install" from a registry.** Until a publish, users install the packed tarballs.
- **A live URL in the README on day one.** Screenshots captured by Playwright stand in.
